# H34d: add real cross-layer credit to the working local stack, by direct feedback alignment (codex: implement + smoke only; no network)

Read `/root/pdp/CLAUDE.md`, the scoring table of `results/h34b/RESULTS.md`, `handoffs/2026-11-18_codex_h34b_plain_depth.md` (with amendment) and
`h34b_plain_depth.py`.

## Why
H34b: the local stack where every layer predicts on its own loss deepens with diminishing returns (tail: 1 → 2 → 4 → 6 layers = 3.275, 3.138, 3.091, 3.081)
and beats a single layer of matched width by about 0.1, but the learned gate is not what makes it work (frozen equal weights +0.012). No layer learns
anything for the layers above it. H34d gives every layer a second, global signal without a backward pass: the stack's final error sent to each layer
through a fixed random matrix (direct feedback alignment, Nøkland 2016), on top of its own loss.

## Setup
H34b's `plain_4` exactly (180,000 bytes of enwik8, tail 40,000–180,000, N = 128, own loss per layer, learned GeoMixer, stateless input normalisation,
zero-init readouts, f detached), seeds 0 and 1.
## Arms
- `plain_4`: rerun (same code path as the others).
- `dfa_4`: at each layer k, the gradient on its hidden state is ∂L_own/∂h_k + α_k · B_k e, where e = p_mix − y (the stack's error, detached) and B_k is a fixed
  random matrix (2N × 256, entries N(0, 1/256), rng `default_rng(7_000 + 100·seed + k)`) mapping e into layer k's state (real and imaginary parts). α_k is set
  per chunk so that ‖α_k B_k e‖ equals ‖∂L_own/∂h_k‖ (the two signals at equal strength; fixed rule, not tuned). The trace rule then carries the sum into ν, θ,
  B_in and the embedding, as it carries the own-loss gradient now. Readouts learn from the own loss only.
- `dfa_only_4`: as dfa_4 but layers k ≥ 2 get only the DFA term on their state (their readouts still learn their own loss). Report only.
Write `h34d_dfa.py` (import from h34b; do not edit it), kernels `kaggle/h34d/<arm>-s<seed>/` (6, private, CPU, no internet, code dataset
`ezzzzzx/pdp-code-h34d`), a resumable dispatcher (loads `.env`; account kernels ≤ 5; ≤ 3 at once), `summarize.py` with a scoring table at the top
(dfa_4 − plain_4, dfa_only_4 − plain_4, tail and full, per seed, counts).
**Smoke:** (1) with α forced to 0, dfa_4 equals plain_4 on 8,192 bytes to 1e-9; (2) the trace-carried DFA term equals autograd through the layer's own
recurrence for a 512-byte check (≤ 1e-4 relative); (3) ‖α_k B_k e‖ = ‖∂L_own/∂h_k‖ per chunk; (4) prequential prefix check; (5) wall ≤ 85 min.
**Bar (orchestrator; do not change), tail, both seeds:** dfa_4 − plain_4 ≤ −0.03.
